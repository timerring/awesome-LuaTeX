\subsubsection{GitHub Stars Fetcher}

This package allows you to automatically fetch and display GitHub repository star counts in real-time.

\paragraph{Introduction}

The GitHub Stars Fetcher demonstrates how to use LuaTeX to fetch GitHub repository star counts dynamically during document compilation.

\paragraph{Load Lua Script}

First, load the Lua script in your document:

\begin{verbatim}
\directlua{dofile("packages/github/github-stars.lua")}
\end{verbatim}

% Note: We will load all scripts together later in "Other GitHub Metrics" section
% So we don't load github-stars.lua here to avoid duplicate command definitions


\paragraph{How It Works}

This script:
\begin{enumerate}
    \item Uses shields.io API to fetch GitHub star count (bypasses GitHub API rate limit)
    \item Parses SVG response to extract star count
    \item Formats the output:
    \begin{itemize}
        \item $\geq 1000$ stars: displays as "x.xk+"
        \item $< 1000$ stars: rounds down to nearest 10, displays as "xx+"
    \end{itemize}
\end{enumerate}

\paragraph{Usage Instructions}

Use the \verb|\getgithubstars{owner/repo}| command in your LaTeX document.

Example:

\begin{verbatim}
\getgithubstars{torvalds/linux}
\end{verbatim}

Compilation command:

\begin{verbatim}
lualatex --shell-escape your-document.tex
\end{verbatim}

\textbf{Note:} Compilation requires the \texttt{--shell-escape} option to execute external shell commands.

\paragraph{Usage Examples}

\begin{itemize}
    \item \textbf{Linux Kernel:} \getgithubstars{torvalds/linux} stars
    \item \textbf{Matchengine Rust:} \getgithubstars{rqzrqh/matchengine_rust} stars
\end{itemize}
